# Wrapper Engine

## Описание

Проект реализует движок (**Engine**) для вызова методов классов по имени и шаблонную обёртку (**FunctionWrapper**) над методами с произвольной сигнатурой.

Engine позволяет регистрировать методы объектов под строковыми именами и вызывать их, зная только имя команды и набор аргументов.  
Вызываемые методы являются обычными методами классов и не зависят от движка.

---

## Поддерживаемый функционал

- методы с произвольным количеством аргументов  
- произвольные типы аргументов  
- методы с возвращаемым значением любого типа  
- методы с возвращаемым типом `void`  
- потокобезопасная регистрация и выполнение команд  

Для реализации используются **variadic templates** и распаковка аргументов во время компиляции.

Аргументы и результаты вызова передаются через универсальный контейнер `Container`.

---

## Тестирование

В проекте реализованы runtime-тесты с использованием стандартных `assert`, без сторонних библиотек.

Тестами проверяется:

- вызов метода с возвращаемым значением  
- вызов `void`-метода с изменением состояния объекта  
- вызов метода со смешанными типами аргументов  

Все тесты запускаются автоматически при старте программы и выводят результат выполнения в консоль.

---

## Сборка и запуск

### Требования

- компилятор с поддержкой **C++17** или новее  
- **CMake** версии **3.16** или выше  

### Сборка проекта

```bash
mkdir build
cd build
cmake ..
cmake --build .
```
### Запуск
```bash
./wrapper
```

При запуске выполняются все тесты.
В случае успешного выполнения выводится сообщение об успешном завершении тестовой сессии.
